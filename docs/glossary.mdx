# Glossary

This glossary provides definitions for key terms used throughout the book, particularly those related to Physical AI, Humanoid Robotics, ROS 2, simulation, and Vision-Language-Action (VLA) systems.

## A

**Action (ROS 2)**
: A communication pattern in ROS 2 designed for long-running, goal-based tasks that require periodic feedback and can be preempted. It consists of a goal, feedback, and result.

**ASR (Automatic Speech Recognition)**
: The process by which a computer recognizes spoken words and converts them into text. OpenAI Whisper is an example of an ASR system.

## D

**DDS (Data Distribution Service)**
: An open international standard for real-time, high-performance, and scalable data exchange. ROS 2 uses DDS as its underlying communication middleware.

**Digital Twin**
: A virtual model of a physical object or system that behaves similarly to its real-world counterpart, allowing for testing, monitoring, and optimization in a simulated environment.

## G

**Gazebo**
: A powerful open-source 3D robotics simulator widely used in the ROS ecosystem, offering robust physics simulation and a rich set of sensor models.

## H

**Humanoid Robotics**
: A field of robotics focused on designing and building robots that mimic the human form and capabilities, often for operating in human-centric environments.

## I

**IMU (Inertial Measurement Unit)**
: An electronic device that measures and reports a body's specific force, angular rate, and sometimes the orientation of the body, using a combination of accelerometers, gyroscopes, and magnetometers.

**Isaac ROS**
: A collection of hardware-accelerated ROS 2 packages developed by NVIDIA, designed to boost the performance of robotic applications using NVIDIA GPUs.

**Isaac Sim**
: NVIDIA's powerful robotics simulation and synthetic data generation tool, built on the Omniverse platform, offering highly realistic and physically accurate environments.

## L

**LiDAR (Light Detection and Ranging)**
: A remote sensing method that uses light in the form of a pulsed laser to measure ranges (variable distances) to the Earth. In robotics, used for mapping and obstacle detection.

**LLM (Large Language Model)**
: An artificial intelligence program trained on a vast amount of text data, capable of understanding, generating, and manipulating human language. Used in VLA systems for planning and intent extraction.

## N

**Nav2 (Navigation2)**
: The ROS 2 navigation stack, providing a flexible and configurable framework for autonomous navigation in complex environments.

**NLU (Natural Language Understanding)**
: A subfield of natural language processing (NLP) that focuses on enabling computers to understand the meaning of human language. In VLA, used to extract intent and entities from text.

**Node (ROS 2)**
: An executable process that performs computation within the ROS 2 graph. Each node should ideally be responsible for a single, modular task.

## O

**Omniverse**
: An open platform developed by NVIDIA for virtual collaboration and real-time physically accurate simulation, built on Universal Scene Description (USD).

## P

**Physical AI**
: Artificial intelligence systems that operate and interact with the physical world through sensors and actuators, embodying intelligence in a tangible form.

**Physics Engine**
: Software that simulates physical laws (e.g., gravity, collisions, friction) to provide realistic behavior for objects in a virtual environment.

**Prompt Engineering**
: The process of designing and refining input queries or "prompts" to optimize the output of a large language model for a specific task.

## R

**rclpy**
: The Python client library for ROS 2, allowing developers to write ROS 2 nodes, publishers, subscribers, services, and actions using Python.

**Rigid Body Dynamics (RBD)**
: A branch of physics and engineering that models the motion of rigid bodies under the influence of forces and torques. Essential for simulating robot movement and collisions.

**ROS 2 (Robot Operating System 2)**
: A flexible framework for writing robot software, providing tools, libraries, and conventions for communication, hardware abstraction, and application development.

## S

**SDF (Simulation Description Format)**
: Gazebo's native XML-based format used to describe everything in a simulation, including robots, static objects, sensors, and the environment itself.

**Service (ROS 2)**
: A communication pattern in ROS 2 for synchronous request/reply interactions between nodes, suitable for discrete operations that require an immediate response.

**Sim-to-Real Transfer**
: The process of transferring models or policies trained in a simulated environment to a real-world robot, aiming to bridge the "reality gap."

**Synthetic Data Generation (SDG)**
: The programmatic creation of artificial datasets in simulation, often with ground-truth labels, used for training AI models when real-world data is scarce.

## T

**Topic (ROS 2)**
: A communication pattern in ROS 2 for asynchronous, one-to-many data streaming, where nodes publish messages to a topic and other nodes subscribe to receive them.

## U

**Unity**
: A cross-platform game engine and real-time 3D development platform that can be adapted for robot simulation, especially for visually rich environments and human-robot interaction.

**URDF (Unified Robot Description Format)**
: An XML-based file format in ROS used to describe the kinematic and dynamic properties of a robot, including its links, joints, and sensors.

**USD (Universal Scene Description)**
: An open-source 3D scene description technology developed by Pixar, forming the foundation of NVIDIA Omniverse and Isaac Sim.

## V

**VLA (Vision-Language-Action)**
: A type of AI system that integrates visual perception, natural language understanding, and robot action execution to enable robots to interpret and respond to complex human commands.

**VSLAM (Visual Simultaneous Localization and Mapping)**
: A process of simultaneously estimating a robot's pose (localization) and building a map of its environment (mapping) using visual input from cameras.

## W

**Whisper**
: OpenAI's open-source automatic speech recognition (ASR) system, capable of transcribing audio into text with high accuracy.
