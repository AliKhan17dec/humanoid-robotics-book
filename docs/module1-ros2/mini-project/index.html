Mini-Project: Building a Smart Sensor Package

This mini-project will guide you through creating a simple ROS 2 Python package that simulates a "smart sensor." This sensor will publish temperature readings to a topic, and also respond to a service call to provide its current status.

Objectives​

  • Create a new ROS 2 Python package.
  • Implement a ROS 2 Node that acts as a temperature sensor publisher.
  • Implement a ROS 2 Service Server within the same node to report sensor status.
  • Implement a ROS 2 Service Client to query the sensor's status.
  • Understand basic package structure and build processes.

Scenario​

Imagine you have a robot equipped with a smart temperature sensor. This sensor continuously monitors the environment and broadcasts the temperature. Additionally, a diagnostic system can query the sensor for its operational status (e.g., "OK," "Error").

Task Steps​

Step 1: Create a New ROS 2 Python Package​

Use the ROS 2 command-line tool to create a new package for your sensor.

cd ~/ros2_ws/src # Navigate to your ROS 2 workspace source directory
ros2 pkg create --build-type ament_python smart_sensor_pkg --dependencies rclpy std_msgs example_interfaces

This command creates smart_sensor_pkg and declares its dependencies.

Step 2: Implement the Smart Sensor Node (Publisher & Service Server)​

Inside your smart_sensor_pkg/smart_sensor_pkg directory, create a Python file (e.g., smart_sensor_node.py) with the following logic:

  1. Node Initialization: Create a ROS 2 Node named smart_temperature_sensor.
  2. Temperature Publisher:
    • Create a publisher that publishes std_msgs.msg.Float32 messages to a topic named /temperature_reading.
    • Use a timer to publish a simulated temperature value (e.g., incrementing or random) every 1 second.
  3. Status Service Server:
    • Create a service server that uses example_interfaces.srv.Trigger (or a custom service type if you prefer).
    • The service server should respond with a success flag and a message indicating the sensor's status (e.g., "Sensor OK" or "Battery Low" randomly).

Example Code Structure for smart_sensor_node.py:

# smart_sensor_pkg/smart_sensor_pkg/smart_sensor_node.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import Float32
from example_interfaces.srv import Trigger # Or your custom service type
import random

class SmartTemperatureSensor(Node):
    def __init__(self):
        super().__init__('smart_temperature_sensor')
        self.publisher_ = self.create_publisher(Float32, '/temperature_reading', 10)
        self.timer = self.create_timer(1.0, self.publish_temperature)
        self.srv = self.create_service(Trigger, 'get_sensor_status', self.get_sensor_status_callback)
        self.current_temperature = 25.0
        self.get_logger().info("Smart Temperature Sensor Node has been started.")

    def publish_temperature(self):
        msg = Float32()
        self.current_temperature += random.uniform(-0.5, 0.5) # Simulate temperature fluctuation
        msg.data = self.current_temperature
        self.publisher_.publish(msg)
        self.get_logger().info(f'Publishing temperature: {msg.data:.2f} °C')

    def get_sensor_status_callback(self, request, response):
        response.success = True
        if random.random() > 0.9: # Simulate a small chance of error
            response.message = "Sensor Error: Calibration needed."
            response.success = False
        else:
            response.message = f"Sensor OK. Current Temp: {self.current_temperature:.2f} °C"
        self.get_logger().info(f'Responding to status request: {response.message}')
        return response

def main(args=None):
    rclpy.init(args=args)
    node = SmartTemperatureSensor()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

Step 3: Update setup.py​

Modify your smart_sensor_pkg/setup.py to include the entry point for your new node.

from setuptools import find_packages, setup
import os
from glob import glob

package_name = 'smart_sensor_pkg'

setup(
    name=package_name,
    version='0.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        (os.path.join('share', package_name, 'launch'), glob(os.path.join('launch', '*launch.[pxy][yeml]'))),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='Your Name',
    maintainer_email='you@example.com',
    description='Smart sensor package for temperature publishing and status service',
    license='Apache-2.0',
    tests_require=['pytest'],
    entry_points={
        'console_scripts': [
            'smart_sensor_node = smart_sensor_pkg.smart_sensor_node:main',
            # Add other nodes here if you create more
        ],
    },
)

Step 4: Build Your Package​

Navigate to your ROS 2 workspace root (~/ros2_ws) and build your package.

colcon build --packages-select smart_sensor_pkg

Source your workspace:

. install/setup.bash

Step 5: Test Your Sensor Node​

  1. Run the sensor node: 
    ros2 run smart_sensor_pkg smart_sensor_node
  2. Monitor temperature readings (in a new terminal, after sourcing workspace): 
    ros2 topic echo /temperature_reading
  3. Query sensor status (in another new terminal): 
    ros2 service call /get_sensor_status example_interfaces/srv/Trigger "{}"
    Observe the responses, including the simulated error.

Step 6: Implement a Status Monitor Client​

Create a separate Python file (smart_sensor_pkg/smart_sensor_pkg/status_monitor_client.py) that periodically calls the get_sensor_status service and logs the response.

Example Code Structure for status_monitor_client.py:

# smart_sensor_pkg/smart_sensor_pkg/status_monitor_client.py
import rclpy
from rclpy.node import Node
from example_interfaces.srv import Trigger

class SensorStatusMonitor(Node):
    def __init__(self):
        super().__init__('sensor_status_monitor')
        self.client = self.create_client(Trigger, 'get_sensor_status')
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Status service not available, waiting...')
        self.timer = self.create_timer(5.0, self.call_status_service) # Call every 5 seconds
        self.get_logger().info("Sensor Status Monitor Node has been started.")

    def call_status_service(self):
        req = Trigger.Request()
        self.future = self.client.call_async(req)
        self.future.add_done_callback(self.response_callback)

    def response_callback(self, future):
        try:
            response = future.result()
            self.get_logger().info(f'Status Response: Success={response.success}, Message="{response.message}"')
        except Exception as e:
            self.get_logger().error(f'Service call failed: {e}')

def main(args=None):
    rclpy.init(args=args)
    node = SensorStatusMonitor()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

Remember to add status_monitor_client = smart_sensor_pkg.status_monitor_client:main to the entry_points in setup.py and rebuild your package.

Expected Outcome​

You should have a working ROS 2 package that:

  • Publishes simulated temperature data.
  • Responds to status queries with dynamic messages.
  • Can be monitored by a separate client node.

This mini-project demonstrates the integration of ROS 2 topics and services within a single, functional package.

Troubleshooting​

  • Service not found: Ensure both server and client nodes are running and your workspace is sourced.
  • Message type errors: Double-check the message types used by publishers/subscribers and service definitions.
  • Python interpreter: Always use python3 for ROS 2 Python scripts.
