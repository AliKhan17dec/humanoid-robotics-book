# Mini-Project: Building a Custom Gazebo World & Robot Spawn

This mini-project will guide you through creating a simple, custom Gazebo world and then spawning a robot into it using ROS 2 tools. You'll learn how to define static elements, lighting, and use your previously created URDF to populate the environment.

## Objectives

*   Create a custom Gazebo `.world` file.
*   Define basic static elements within the world (e.g., ground plane, simple walls).
*   Launch Gazebo with your custom world.
*   Use a ROS 2 Python script to spawn a robot (e.g., the `diff_drive_robot` from the previous chapter) into this custom world.
*   Verify the robot appears and interacts with the world.

## Scenario

You need to test a robot's navigation capabilities in a confined space. To do this, you'll design a simple test arena in Gazebo and programmatically place your robot at a starting point.

## Task Steps

### Step 1: Create Your Custom Gazebo World

Create a new directory for your world files (e.g., `worlds`) within your ROS 2 package or a dedicated simulation package. Inside this directory, create an XML file (e.g., `my_test_world.world`).

**Example: `my_test_world.world`**
```xml
<?xml version="1.0" ?>
<sdf version="1.6">
  <world name="my_test_world">
    <!-- Light Source -->
    <include>
      <uri>model://sun</uri>
    </include>

    <!-- Ground Plane -->
    <include>
      <uri>model://ground_plane</uri>
    </include>

    <!-- Simple Box Obstacles -->
    <model name="wall_1">
      <pose>2 0 0.5 0 0 0</pose>
      <static>true</static>
      <link name="link">
        <visual name="visual">
          <geometry><box><size>0.1 4 1</size></box></geometry>
          <material><script><name>Gazebo/Grey</name></script></material>
        </visual>
        <collision name="collision">
          <geometry><box><size>0.1 4 1</size></box></geometry>
        </collision>
      </link>
    </model>

    <model name="wall_2">
      <pose>-2 0 0.5 0 0 0</pose>
      <static>true</static>
      <link name="link">
        <visual name="visual">
          <geometry><box><size>0.1 4 1</size></box></geometry>
          <material><script><name>Gazebo/Grey</name></script></material>
        </visual>
        <collision name="collision">
          <geometry><box><size>0.1 4 1</size></box></geometry>
        </collision>
      </link>
    </model>

    <model name="wall_3">
      <pose>0 2 0.5 0 0 1.57079632679</pose> <!-- Rotate 90 degrees -->
      <static>true</static>
      <link name="link">
        <visual name="visual">
          <geometry><box><size>0.1 4 1</size></box></geometry>
          <material><script><name>Gazebo/Grey</name></script></material>
        </visual>
        <collision name="collision">
          <geometry><box><size>0.1 4 1</size></box></geometry>
        </collision>
      </link>
    </model>
    
    <model name="wall_4">
      <pose>0 -2 0.5 0 0 1.57079632679</pose> <!-- Rotate 90 degrees -->
      <static>true</static>
      <link name="link">
        <visual name="visual">
          <geometry><box><size>0.1 4 1</size></box></geometry>
          <material><script><name>Gazebo/Grey</name></script></material>
        </visual>
        <collision name="collision">
          <geometry><box><size>0.1 4 1</size></box></geometry>
        </collision>
      </link>
    </model>

  </world>
</sdf>
```
Save this file, for instance, in `my_simulation_pkg/worlds/my_test_world.world`.

### Step 2: Launch Gazebo with Your Custom World

You can launch Gazebo with your custom world using the `gazebo_ros` package.
First, make sure `my_simulation_pkg` is built and sourced.

```bash
ros2 launch gazebo_ros gazebo.launch.py \
    gazebo_args="-s libgazebo_ros_factory.so -r -w $(ros2 pkg prefix my_simulation_pkg)/share/my_simulation_pkg/worlds/my_test_world.world"
```
*(Note: Adjust the path to your `.world` file based on your package structure.)*

### Step 3: Use the Spawn Robot Node to Add Your Robot

In a new terminal, after launching Gazebo with your custom world and sourcing your workspace, use the `spawn_robot_node.py` script you created in T020. Remember to specify the path to your robot's URDF file (e.g., `diff_drive_robot.urdf` from `module2-digital-twin/02-gazebo.mdx`).

```bash
ros2 run code_module2 spawn_robot_node \
    --ros-args -p robot_name:="my_custom_diff_drive" \
               -p robot_urdf_path:="/path/to/your/diff_drive_robot.urdf" \
               -p x_pos:=0.0 -p y_pos:=0.0 -p z_pos:=0.1
```
*(Note: Replace `code_module2` with the actual ROS 2 package name you are using for the spawn script if it's not `code_module2`.)*

### Step 4: Verify and Interact

*   Observe Gazebo: Your robot should appear in the custom world, resting on the ground plane.
*   Test with the controller: Launch the `diff_drive_controller.py` from T020 to see your robot move and potentially collide with the walls you created.

## Expected Outcome

You will have successfully:
*   Created a custom Gazebo simulation environment.
*   Launched Gazebo with this custom environment.
*   Spawned a robot into the world using a ROS 2 Python script.
*   Confirmed basic interaction between the robot and the world's static elements.

## Troubleshooting

*   **World not loading**: Double-check the path to your `.world` file in the `ros2 launch` command.
*   **Robot not spawning**:
    *   Ensure the `spawn_entity` service is running (it should be if Gazebo is launched with `libgazebo_ros_factory.so`).
    *   Verify the `robot_urdf_path` is correct and the URDF is valid.
    *   Check the Gazebo console for errors.
*   **Robot falls through floor**: Check the URDF's `<inertial>` properties for the base link and the `z_pos` when spawning. Ensure collision geometries are properly defined.
