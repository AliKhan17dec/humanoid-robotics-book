# Voice-to-Action: Translating Speech to Robot Intent (Whisper & NLU)

One of the most intuitive ways for humans to interact with robots is through natural language, particularly voice commands. This chapter explores how to bridge the gap between spoken language and a robot's executable actions, focusing on using OpenAI's Whisper for robust speech-to-text conversion and Natural Language Understanding (NLU) techniques to extract actionable intent.

## 1. The Challenge of Natural Language Interaction

For a robot to understand a command like "Robot, go to the kitchen and grab the red apple," it needs to perform several complex steps:

1.  **Speech Recognition (ASR)**: Convert the spoken audio into written text.
2.  **Natural Language Understanding (NLU)**: Parse the text to identify the robot's intended actions, objects, and locations (i.e., extract "intent" and "entities").
3.  **Task Planning**: Break down the high-level intent into a sequence of low-level robot actions.
4.  **Action Execution**: Translate these actions into motor commands and execute them.

This chapter focuses on the first two steps: ASR and NLU for intent extraction.

## 2. Speech Recognition with OpenAI Whisper

OpenAI Whisper is a general-purpose, open-source automatic speech recognition (ASR) system. It can transcribe audio into text and translate it into multiple languages. Whisper is trained on a massive dataset of diverse audio, making it highly robust to accents, background noise, and technical jargon.

### Using Whisper (Python Example)

Whisper can be used via its Python API. First, install the necessary libraries:

```bash
pip install openai-whisper
```

Then, you can transcribe an audio file:

```python
# code/module4/whisper_transcript.py
import whisper
import os

def transcribe_audio(audio_path, model_name="base"):
    """
    Transcribes an audio file using OpenAI Whisper.
    Args:
        audio_path (str): Path to the audio file (e.g., .wav, .mp3).
        model_name (str): The Whisper model to use (e.g., 'tiny', 'base', 'small', 'medium', 'large').
    Returns:
        str: The transcribed text.
    """
    if not os.path.exists(audio_path):
        print(f"Error: Audio file not found at {audio_path}")
        return ""

    print(f"Loading Whisper model '{model_name}'...")
    model = whisper.load_model(model_name)
    print(f"Transcribing '{audio_path}'...")
    result = model.transcribe(audio_path)
    transcript = result["text"]
    print(f"Transcript: {transcript}")
    return transcript

if __name__ == "__main__":
```

## 3. Natural Language Understanding (NLU) for Intent Extraction

Once we have the text transcript, the next step is to extract the "intent" (what the user wants the robot to do) and relevant "entities" (objects, locations, values). This can be done using various NLU techniques, ranging from rule-based systems to machine learning models or directly with Large Language Models (LLMs).

### Rule-Based NLU

For simple, constrained command sets, you can use regular expressions or keyword matching.

**Example: Extracting simple commands**
```python
# code/module4/rule_based_nlu.py
import re

def extract_intent_and_entities(command_text: str):
    command_text = command_text.lower()
    intent = "unknown"
    entities = {}

    if "go forward" in command_text:
        intent = "move_forward"
        match = re.search(r"(\d+)\s*(meter|meters)", command_text)
        if match:
            entities["distance_m"] = float(match.group(1))
    elif "turn left" in command_text:
        intent = "turn_left"
        match = re.search(r"(\d+)\s*(degree|degrees)", command_text)
        if match:
            entities["angle_deg"] = float(match.group(1))
    elif "pick up" in command_text:
        intent = "pick_up"
        match = re.search(r"(red|blue|green)\s+(block|cube)", command_text)
        if match:
            entities["object_color"] = match.group(1)
            entities["object_type"] = match.group(2)
    
    return {"intent": intent, "entities": entities}

if __name__ == "__main__":
    commands = [
        "Robot, go forward five meters.",
        "Turn left ninety degrees.",
        "Please pick up the blue block.",
        "What's the weather like?"
    ]

    for cmd in commands:
        result = extract_intent_and_entities(cmd)
        print(f"Command: '{cmd}' -> {result}")
```

For more complex and flexible commands, LLMs can be directly prompted to perform NLU. This is a powerful approach that simplifies development and allows for more natural conversation.

## 4. Converting Intent to ROS 2 Commands

Once the intent and entities are extracted, the next step is to map these to specific ROS 2 commands. This can involve:

*   **Service Calls**: For discrete actions (e.g., "activate gripper").
*   **Action Goals**: For long-running tasks (e.g., "navigate to a point").
*   **Topic Publishing**: For continuous control (e.g., sending `Twist` commands based on "move forward").

This mapping logic often resides in a central "command dispatch" node or an LLM-based planner, which we will explore in the next chapter.

## Conclusion

Translating voice commands into actionable robot intents is a fundamental step towards creating truly interactive humanoid robots. By combining robust ASR systems like Whisper with flexible NLU techniques, whether rule-based or LLM-driven, we can empower robots to understand and respond intelligently to human instructions, paving the way for intuitive human-robot collaboration.
