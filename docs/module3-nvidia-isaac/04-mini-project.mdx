# Mini-Project: Synthetic Data Generation & Perception Training (Conceptual)

This mini-project will conceptually guide you through the process of setting up a simple scene in NVIDIA Isaac Sim, generating synthetic data with ground-truth labels, and then outlining how you would use this data to train a basic perception model (e.g., for object detection). **Note**: The actual training of deep learning models is outside the scope of this mini-project's direct execution due to computational requirements, but the workflow is thoroughly explained.

## Objectives

*   Set up a simple scene in Isaac Sim with multiple instances of a target object.
*   Configure Isaac Sim's Synthetic Data Generation (SDG) tools to generate RGB images, segmentation masks, and 2D bounding boxes.
*   Understand the output format of synthetic datasets.
*   Outline the steps to use this synthetic data to train a simple object detection model.

## Scenario

You are tasked with enabling a humanoid robot to identify a specific type of object (e.g., a "red cube") in various environments. Collecting real-world data for all possible lighting conditions, angles, and occlusions is time-consuming and difficult. Synthetic data generation offers a powerful alternative.

## Task Steps (within Isaac Sim)

### Step 1: Launch Isaac Sim and Create a Simple Scene

1.  Launch NVIDIA Isaac Sim.
2.  Start a new empty stage (File > New > Empty Stage).
3.  Add a ground plane (Create > Physics > Ground Plane).
4.  Add a simple light source (Create > Light > Dome Light).

### Step 2: Add Target Objects and a Camera

1.  **Add Target Objects**:
    *   Add multiple instances of a primitive shape (e.g., a "Cube") to the scene (Create > Mesh > Cube).
    *   Vary their positions, rotations, and scales. Change their colors/materials to simulate variations. Ensure some are partially occluded.
    *   Give each instance a unique name (e.g., `cube_1`, `cube_2`).
2.  **Add a Camera**:
    *   Add an "OmniGraph Camera" to the scene (Create > Camera > Camera).
    *   Position and rotate the camera to view the target objects from various angles. You can animate the camera's movement for more diverse data.
3.  **Assign Semantic Labels**:
    *   For each target object, select it in the Stage window.
    *   In the Property window, add a "Semantics" component (Add > primvar > OmniGraph Primvars > Semantics).
    *   Set the "Type" to `class` and the "Data" to `RedCube` (or whatever your target object is). This is crucial for segmentation and bounding box generation.

### Step 3: Configure Synthetic Data Generation (SDG)

Isaac Sim provides tools (via Extensions) to configure SDG.

1.  **Enable SDG Extensions**: Ensure `omni.isaac.synthetic_utils` and `omni.isaac.ros_bridge` (if you want ROS 2 output) are enabled in the Extension Manager (Window > Extensions).
2.  **Add a `CameraHelper` and `RgbCamera`**: To your camera prim in the Stage window, add the `Isaac Read Camera Parameters` component (Add > Isaac > Read Camera Parameters) and `RgbCamera` component (Add > Isaac > RgbCamera).
3.  **Configure Annotators**:
    *   Attach annotators to your camera. In the "Property" window of your camera, select "Add" > "Isaac" > "Annotators".
    *   Add: `Rgb`, `InstanceSegmentation`, `BoundingBox2D` (and optionally `Depth`).
    *   Configure output directory and frequency for data collection.
4.  **Randomize Scene Properties (Optional but Recommended)**:
    *   To make your trained model more robust, introduce randomization.
    *   Add "Randomizers" (e.g., `omni.isaac.synthetic_utils.scripts.SyntheticDataPipeline.LODRandomizer` or `omni.isaac.synthetic_utils.scripts.SyntheticDataPipeline.TextureRandomizer`) as extensions.
    *   You can randomize lighting, object positions, textures, and camera angles.

### Step 4: Generate Synthetic Data

1.  Run the simulation.
2.  Isaac Sim's SDG tools will automatically save image files (RGB), segmentation masks, and bounding box annotations to your specified output directory.

## Task Steps (Outside Isaac Sim: Conceptual Training Workflow)

### Step 5: Prepare Dataset for Training

1.  The generated synthetic data will often be in a format like COCO or KITTI.
2.  You will need to organize this data into training, validation, and test sets.
3.  Ensure your dataset includes the RGB images and the corresponding bounding box/segmentation annotations for your target object (`RedCube`).

### Step 6: Select and Configure a Perception Model

1.  **Choose a Model Architecture**: Select a suitable object detection model (e.g., YOLOv8, SSD, Faster R-CNN, EfficientDet). For beginners, pre-trained models fine-tuned on custom datasets are a good starting point.
2.  **Framework**: Use a deep learning framework like PyTorch or TensorFlow.
3.  **Configuration**: Adjust model parameters, learning rates, and data augmentation techniques.

### Step 7: Train the Perception Model

1.  Load your synthetic dataset.
2.  Initialize your chosen model.
3.  Start the training process, monitoring metrics like loss, precision, and recall.
4.  Save the trained model weights.

### Step 8: Evaluate and Deploy (Conceptual)

1.  **Evaluate**: Test your trained model on the validation and test sets.
2.  **Deploy**: For deployment on a Jetson Orin or other NVIDIA platform, you would typically convert your model to an optimized format like ONNX or TensorRT. This optimized model would then be integrated into a ROS 2 node (potentially using Isaac ROS GEMs like `isaac_ros_detectnet`) for real-time inference on a robot.

## Expected Outcome

You will have a comprehensive understanding of how to:
*   Create a scene in Isaac Sim.
*   Generate high-quality, labeled synthetic data for perception tasks.
*   Outline the full workflow from synthetic data to a trained object detection model suitable for robotic deployment.

## Troubleshooting

*   **SDG not generating data**: Check if all SDG extensions are enabled and configured correctly. Verify the output directory has write permissions.
*   **Missing semantic labels**: Ensure all objects you want to annotate have the "Semantics" primvar attached and correctly configured.
*   **Isaac Sim crashes**: Ensure you have sufficient GPU memory and an updated NVIDIA driver.
*   **Model training issues**: This is a vast field. Common issues include incorrect data loading, inappropriate learning rates, or model architecture mismatch. Start with known working examples and datasets.
